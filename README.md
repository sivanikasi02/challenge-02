problem TripCalc: A student is planning a road trip. Write a C program to read the total distance to be travelled (in
kilometres), the vehicle's mileage (kilometres per litre), and the current fuel price per litre. Calculate and
display the amount of fuel required for the trip and the total fuel cost.

Algorithm:
1.Start
2.Read the total distance to be travelled (distance).
3.Read the vehicle mileage (mileage).
4.Read the fuel price per litre (price).
5.Calculate fuel required: fuel = distance / mileage
6.Calculate total fuel cost: cost = fuel × price
7.Display the fuel required.
8.Display the total fuel cost.
9.Stop
